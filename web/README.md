# Веб-интерфейс «ГУСЬ ПЕРЕВОДИЛА»

Лёгкая обёртка над существующим конвейером. Логика сборки ролика **не переписана** —
веб-приложение только запускает `auto_news.py` как subprocess и транслирует его
вывод в браузер через WebSocket.

## Запуск

```cmd
start_web.bat
```

или вручную:

```cmd
D:\AI\python310\python.exe D:\AI\VIDEO_PIPELINE\web\app.py
```

Открыть: <http://127.0.0.1:8000>

## Зависимости

```cmd
D:\AI\python310\python.exe -m pip install fastapi uvicorn jinja2 python-multipart websockets
```

## Структура

```
web/
├── app.py               # FastAPI: REST + WebSocket
├── templates/
│   ├── index.html       # главная: форма + живой лог
│   └── results.html     # готовые ролики
├── static/
│   ├── css/style.css
│   └── js/app.js
└── uploads/             # загруженные b-roll
```

## API

| Метод  | Путь                 | Назначение                                   |
|--------|----------------------|----------------------------------------------|
| POST   | `/api/upload`        | загрузка b-roll → возвращает путь для `--asset` |
| POST   | `/api/process`       | запуск конвейера, возвращает `job_id`        |
| GET    | `/api/jobs`          | список задач                                 |
| GET    | `/api/jobs/{id}`     | статус задачи                                |
| GET    | `/api/results`       | список готовых роликов                       |
| GET    | `/api/video/{name}`  | потоковое воспроизведение                    |
| GET    | `/api/download/{n}`  | скачать ролик                                |
| POST   | `/api/open-folder`   | открыть папку в проводнике (только локально) |
| WS     | `/ws`                | поток логов в реальном времени               |

## Настройки формы → флаги `auto_news.py`

| Поле формы        | Флаг            |
|-------------------|-----------------|
| Сценарий          | `--script`      |
| Локальный путь    | `--asset`       |
| Ссылка b-roll     | `--video-url`   |
| Сегменты          | `--segments`    |
| Темп речи         | `--factor`      |
| Приватность       | `--privacy`     |
| Категория         | `--category`    |
| Музыка            | `--bed`         |
| Позиция гуся      | `--goose-pos`   |
| Без гуся          | `--no-goose`    |

| Без озвучки       | `--skip-voice`  |
| Без загрузки      | `--skip-download` |
| Без публикации    | `--skip-publish` |

## Публикация

Перед публикацией `auto_news.py` сам вызывает `originality_check.py`.
Если проверка не пройдена — публикация блокируется, в лог пишется `[BLOCK]`.
Отдельно запускать проверку не нужно.

## Что нужно для публичного хостинга

Текущая версия — локальная: она пишет в `D:\AI\VIDEO_PIPELINE` и запускает
F5-TTS/FFmpeg на этой машине. Для публичного доступа «для всех бесплатно»
понадобится:

1. Отдельный сервер/VPS с GPU (F5-TTS идёт через CUDA, ~4–6 минут на ролик).
2. Очередь задач (Redis/RQ или Celery) вместо `asyncio.create_task`.
3. Файлы в S3-подобное хранилище, а не в локальную `output/`.
4. Авторизация и квоты, чтобы публичный сайт не сжёг GPU и YouTube-квоту.
5. Секреты (YouTube OAuth, VK token) — в переменные окружения, а не в файлы.

Правила оригинальности из `ORIGINALITY_GUIDE.md` при этом остаются в силе —
они внутри `auto_news.py` и меняться не должны.
