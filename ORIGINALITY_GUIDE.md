# ORIGINALITY_GUIDE.md — Гайд по оригинальности новостного контента

Этот файл — обязательный стандарт для всех новостных роликов, которые генерирует пайплайн.
Применяй его **автоматически**, без напоминаний, при каждом создании сценария, монтаже и публикации.

## 🎯 Главный принцип

Мы не пересказываем новости — мы создаём **уникальный информационный продукт**.
YouTube в 2026 году поощряет создателей, которые добавляют ценность, а не рерайтят.
Простой пересказ = ограничение охватов. Анализ + графика + своя подача = продвижение.

## 📋 Обязательные правила для каждого ролика

### Правило 1. Смещение фокуса: не «Что?», а «Почему?» и «Что дальше?»
В сценарии обязательно должны быть:
- **Контекст:** почему эта новость важна, что она меняет.
- **Аналитика:** 2–3 тезиса с собственной интерпретацией (не пересказ источника).
- **Прогноз:** что может произойти дальше, какие последствия для зрителя.
- **Хук в первые 3 секунды:** конфликт, вопрос, провокация, неожиданный факт.

**Проверка:** если сценарий можно свести к «X произошло, потому что Y» — это пересказ. Переписывай.

### Правило 2. Уникальный визуальный ряд
Каждый ролик обязан содержать **минимум 3 уникальных визуальных элемента**:
- Анимированная инфографика (цифры, графики, таймлайны) — генерируется через Remotion.
- Уникальный B-roll (ИИ-генерация или специально подобранные кадры под тему, не стандартный сток).
- Динамичная типографика (заголовки, плашки, акцентные слова — синхронизированы с голосом).
- Прогресс-бар, end-card, звуковые акценты (whoosh, click).

**Запрещено:** использовать один и тот же шаблон для всех видео без вариаций. Каждый ролик — свой визуальный стиль в рамках общего бренда.

### Правило 3. Свой сценарий и голос
- **Не читать чужой текст.** Всегда переписывать новость своими словами, добавлять вступление и заключение.
- **Уникальный TTS-голос:** использовать голос с собственной интонацией (не дефолтный), менять темп и паузы в ключевых моментах.
- **Сторителлинг:** подавать новость как историю с конфликтом, героями и развязкой.

### Правило 4. Метаданные без шаблонности
- **Заголовок:** уникальный, с интригой или вопросом. Не копировать заголовок источника.
- **Описание:** 2–3 предложения с ключевыми словами + призыв к обсуждению.
- **Теги:** не только общие (#новости #технологии), но и конкретные по теме.
- **Хэштеги в видео:** 2–3 релевантных, не спамить.

### Правило 5. Автоматическая самопроверка
Перед финальным рендером каждого ролика агент обязан проверить:
- [ ] В сценарии есть аналитика (не только пересказ).
- [ ] В сценарии есть прогноз или вывод.
- [ ] Первые 3 секунды — сильный хук.
- [ ] Есть минимум 3 уникальных визуальных элемента.
- [ ] Заголовок и описание не копируют источник.
- [ ] Длительность 20–50 секунд (оптимум для Shorts).
- [ ] Субтитры синхронизированы (word-by-word, ASS).
- [ ] Есть звуковые акценты и фоновая музыка (не громче голоса).

**Если хотя бы один пункт не выполнен — ролик не публикуется.**

## 🎬 Чеклист по этапам пайплайна

### Этап «Сценарий»
1. Взять новость из RSS.
2. Через LLM:
   - Сжать до 40–50 слов.
   - Добавить хук (первые 3 секунды).
   - Добавить 1 аналитический тезис.
   - Добавить 1 прогноз/вывод.
3. Проверить: это пересказ или новая ценность?

### Этап «Визуал»
1. Проверить: есть ли уникальная инфографика?
2. Проверить: B-roll релевантен теме?
3. Проверить: субтитры word-by-word + подсветка?
4. Проверить: звуковые акценты и музыка на месте?

### Этап «Публикация»
1. Сгенерировать уникальный заголовок (не копию источника).
2. Написать описание с ключевыми словами.
3. Добавить 2–3 релевантных хэштега.
4. Указать категорию «Образование» или «Новости и политика».
5. Добавить дисклеймер (если тема финансовая): «Не является инвестиционной рекомендацией».

## 🚫 Что запрещено

- Простой рерайт новости без аналитики.
- Один и тот же визуальный шаблон без вариаций.
- Копирование заголовков и описаний из источников.
- Использование ИИ-аватаров для финансовых/медицинских тем.
- Публикация без прохождения чеклиста (см. Правило 5).

## 💡 Рекомендуемые темы для максимальной оригинальности

- «Что это значит для вас» — перевод новости на язык обычного пользователя.
- «3 последствия, о которых не говорят» — аналитический разбор.
- «Сравнение с прошлым» — исторический контекст.
- «Ошибка, которую совершают все» — обучающий формат.
- «Прогноз на 6 месяцев» — экспертный взгляд.

## 🔄 Как использовать этот гайд

1. **Перед каждым роликом** — открыть этот файл, пройти по чеклисту.
2. **После генерации сценария** — прогнать самопроверку из Правила 5.
3. **Перед публикацией** — убедиться, что метаданные уникальны.
4. **Раз в неделю** — анализировать статистику: какие ролики сработали, какие нет. Обновлять гайд на основе данных.
