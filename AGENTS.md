# AGENTS.md

## Обязательные документы для чтения

Перед началом работы над любым новостным роликом **всегда** прочитай:
- `ORIGINALITY_GUIDE.md` — стандарт оригинальности контента.
- `ARCHITECTURE.md` — структура проекта.
- `PROJECT_BRIEF.md` — общий бриф.

## Правила

1. **Никогда** не создавай и не публикуй новостной ролик без прохождения чеклиста из `ORIGINALITY_GUIDE.md`.
2. Перед каждым сценарием проверяй: это пересказ или новая ценность? Если пересказ — переписывай.
3. Каждый ролик обязан иметь минимум 3 уникальных визуальных элемента.
4. Если тема чувствительная (финансы, медицина, политика) — добавляй дисклеймер.

## Приоритеты

- Приоритет №1: Оригинальность и аналитика.
- Приоритет №2: Визуальное качество (моушен, субтитры, B-roll).
- Приоритет №3: Скорость и автоматизация.

## Работа с браузером

- Открывать ссылку в системном браузере пользователя через `Start-Process` **один раз** на URL. Не дублировать запуски.
- Для просмотра и снапшотов использовать встроенную панель OpenChamber, а не повторные `Start-Process`.
